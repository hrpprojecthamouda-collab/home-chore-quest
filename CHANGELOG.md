# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-09

### Added
- 🎮 Complete gamified chore system with XP rewards
- ⭐ Level progression system (100 XP per level)
- 🎵 Sound effects for quest completion and level-ups
- 🏷️ Quest categorization (Cleaning, Shopping, Bills, Upgrades)
- 📱 Clean Material Design 3 interface
- 🔄 Riverpod state management implementation
- 🏠 Room cleaning mechanic with visual feedback
- 📊 XP progress tracking with circular indicators
- 🎯 Quest completion animations and rewards

### Features
- Add new quests through gamified dialog
- Complete quests to earn XP and level up
- Clean room to maintain virtual environment
- Browse quests by category
- Visual feedback for all interactions

### Technical
- Built with Flutter SDK ^3.11.3
- State management using Riverpod
- Audio playback with audioplayers package
- Custom page transitions and animations
- Responsive grid layouts
