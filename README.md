# 🏠 Home Chore Quest

A gamified Flutter app that turns household chores into an engaging RPG-style experience! Complete quests, earn XP, level up, and make cleaning your home an adventure.

## ✨ Features

- **🎮 Gamified Experience**: Transform boring chores into exciting quests
- **⭐ XP & Leveling System**: Earn experience points and level up as you complete tasks
- **📊 Progress Tracking**: Visual progress bars and achievement tracking
- **🎵 Sound Effects**: Audio feedback for quest completion and level-ups
- **🏷️ Quest Categories**: Organized chores by type (Cleaning, Shopping, Bills, Upgrades)
- **📱 Clean UI**: Modern Material Design 3 interface
- **🔄 State Management**: Built with Riverpod for predictable state handling

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (^3.11.3)
- Dart SDK (included with Flutter)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/home-chore-quest.git
   cd home-chore-quest
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```

## 🏗️ Architecture

```
lib/
├── models/          # Data models (Quest, QuestCategory)
├── providers/       # Riverpod state management
├── screens/         # UI screens (Home, Category views)
├── services/        # Business logic (Sound service)
```

### Key Technologies
- **Flutter**: Cross-platform UI framework
- **Riverpod**: Reactive state management
- **Audioplayers**: Sound effects and audio feedback
- **Material Design 3**: Modern UI components

## 🎯 How to Use

1. **Add Quests**: Tap "New Mission!" to create household chores as quests
2. **Complete Tasks**: Mark quests as complete to earn XP
3. **Level Up**: Reach 100 XP to advance to the next level
4. **Clean Room**: Use the "Clean" button to maintain your virtual space
5. **Track Progress**: Monitor your XP progress and current level
